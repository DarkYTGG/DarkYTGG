- 🎓 **Educación:** Estudiante de **Técnico Superior Universitario (TSU) en Informática** (cursando el **5to semestre**), apasionado por el desarrollo de software, algoritmos, bases de datos y la arquitectura de sistemas.
- 🚀 **Software en Producción Real:** Creador de [**CaroníPay (Sistema de Nómina)**](https://github.com/DarkYTGG/Sistema-de-Nomina), plataforma empresarial activa para gestión de asistencia, geocercas GPS, integración con la API de Connecteam y cálculo contable de alta precisión.

- 🧠 **Pasión por la IA:** Integración de modelos LLM (**Google Gemini**, **OpenAI GPT-4o**, **DeepSeek**) y **Visión por Computadora** (OCR con ML Kit, inpainting inteligente y procesamiento en pantalla).
- 🌐 **Desarrollo Web & Backend:** Creación de aplicaciones robustas con **Python (FastAPI, Flask)**, **Supabase / PostgreSQL**, **Next.js**, **TypeScript** y **Tailwind CSS**.
